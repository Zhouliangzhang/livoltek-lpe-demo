# M1 步骤07：通信设置

## 工作顺序
1. 使用步骤06当前环境的通信路径，识别 RS485、以太网和 CAN 网络。独立控制器接口不会被合成同一总线；只有显式桥接节点连接其端口。
2. RS485 公共协议、波特率、数据位、校验与停止位只设置一次；每个设备接口分别设置角色和地址。以太网只显示应用协议、服务端口、IP、掩码与必要网关；交换机物理端口不逐个分配 IP。
3. LIVOLTEK 型号模板按主数据版本和通信域匹配，带来源的模板才带入候选值。第三方优先提供匹配模板，无模板则使用空白通用字段。型号模板公共值冲突明确列出，保持厂家待确认。
4. 检查同一网络重复地址（01 与 1 等价）、多个 Modbus 主站、地址范围及公共参数格式。设备级不能覆盖总线公共参数。异常能打开对应设备并聚焦地址字段。
5. 按网络保存到项目版本，OFFLINE、SIMULATION、REAL 分开存储。步骤06路径或型号主数据版本变化后提示重新带入；原工程版本保留。

## 边界
当前是工程计划编辑器，不连接、扫描、写入或读回现场设备。所有设置保持 PENDING；模板的 APPROVED 标签不会把计划自动批准。CI-20 示例尚无已核验的厂家通信默认值，因此不编造波特率、IP 或服务端口。固件适用性、协议细节和厂商允许参数范围仍待厂家依据。网络规划由 EPC 提供。本步骤尚未接入后续配置下发或 M2 的现场适配器。
