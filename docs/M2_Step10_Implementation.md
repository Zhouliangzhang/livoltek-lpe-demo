# Step10 动态响应实现计划

按用户指定的步骤顺序，在当前步骤09完整满足后开放独立模拟动态测试。

- backend/dynamic_response.py：三种合成工况，逐秒反馈控制、设备边界、指令与反馈；计算扰动起点、稳定起点、确认时间、馈网峰值/持续时间和恢复证据。
- 抽取步骤09前置上下文供步骤10复用，绑定最新步骤09运行ID；前置重测或模型变化使旧结果失效。
- frontend/src/DynamicResponse.tsx：三种场景卡、PCC/PV/BESS功率曲线、响应指标、设备原因和M1定位；缺少厂家依据标待确认，真实环境锁定。
- 测试三场景稳定及边界，超时、反馈无效、拒令、恢复不符，幂等与模式隔离；运行实际CI-20页面截图。

演练约定：采样1s、购电目标10kW、容差±2kW且无馈网、连续3点确认、稳定起点不迟于扰动后8s。所有数值与退出策略仅演练，非厂家或现场SAT判据。响应时间及馈网指标由采样计算，不使用预填成功值。

## 已完成与验证
- 三类工况均有56个逐秒合成样本，记录PCC、PV、BESS、负载、设备目标/反馈、当前可用边界和命令回执。
- CI-20 R6模拟扰动后稳定起点：负载突变5s、光伏下降6s、BESS_03充电受限3s；连续3点确认分别为7s、8s、5s。恢复阶段另行计算，不复用扰动结果。
- 增加响应缓慢、表计反馈失效、PV拒令、恢复不符、无权限和缺少演练包场景。反馈无效不生成零值指标，恢复未确认锁定新测试；独立恢复证据保留原失败记录。
- 后端全套97项通过；步骤09/10两项页面测试通过；最终前端构建通过。
- 实际Edge页面核验三场景、响应超时、反馈失效、刷新持久化与独立恢复；最终保留正常三场景结果。当前Codex工作目录outputs/m2-step10-*.png为实际页面截图。

## 限制与解释
这是本地快速计算的合成仿真，非真实iEMS执行时间或现场SAT结果。储能SOC固定55%、功率响应一阶模型、BMS边界即时约束均为演练假设，不宣称厂家控制算法。1s采样下的0s稳定时间表示未观测到越界，仍须连续3点确认。馈网峰值/能量批准限值缺失，因此只展示指标，模拟响应满足不等同于现场零馈合格。真实iEMS适配器、作业授权及批准测试包未接入，REAL端点始终拒绝控制。步骤09前置重测或M1变化会使本步证据失效。
