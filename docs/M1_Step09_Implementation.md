# M1 步骤09：运行策略

依据：iEMS_M1_System_Modeling_Configuration_Design.md 第12节。

## 页面工作顺序
1. 从步骤02读取控制域、执行 iEMS、PCC 和范围；从步骤06当前环境有效控制关系识别光伏、储能设备，不把未映射设备自动加入控制组。
2. 按型号、主数据版本及当前环境固件分组，显示铭牌功率和能量合计。实时可调容量明确为未知。BESS 与 PCS 混合建模时不直接叠加，需明确能力边界。
3. 引用步骤08同环境 PCC 计量草案及换算，缺项支持直接返回计量页面。零馈和自发自用策略都依赖有效计量。
4. 工程师分别勾选拟启用零馈、光伏限功率与储能策略。拟启用仅表示计划，不代表现场生效。
5. 零馈配置允许送电上限、购电目标、控制周期和响应判据；光伏支持站级 kW 或铭牌百分比、分配、爬坡、确认及恢复方案；储能支持自发自用/仅充/仅放、功率限制、SOC边界与预约容量。
6. 启用条件、优先级、项目依据、厂家适用依据、计量失效/拒令/储能不可用方案与恢复观察要求集中展开。无依据不编造定值。
7. 冲突定位修正后保存本控制域草案；缺项允许保留，但页面不能继续准备配置基线。填写文件号不等于批准。

## 检查与边界
前后端检查并网运行依赖、控制关系、多个指令来源、零馈送电上限、优先级、SOC上下限、单向运行功率、超铭牌/百分比限制、预约容量、周期与响应判据及有限非负数值。未知或重叠能力不作为已确认容量。

实时边界规则为项目限值、设备有效反馈、BMS允许、SOC及其他约束的交集。缺输入不能按铭牌放行。计量无效则实测值未知，无法约束送电保留告警并请求厂家协同；恢复要求相关条件均恢复且持续稳定，再异常重新计时。

所有记录PENDING，OFFLINE/SIMULATION/REAL分开保存；不执行控制、保护旁路或开关操作。分时计划、现场配置下发和历史M2适配器消费本次新草案不在此次实现范围。当前降级/恢复字段记录待确认方案，尚不是可执行控制程序。

## 验证
- 28项后端专项检查通过，3项前端控制范围、环境隔离与策略冲突测试通过；生产构建通过。
- Edge实际CI-20：单iEMS关联10台光伏、10台储能；铭牌合计PV1250kW、BESS1250kW/2612kWh，实时能力未知。引用METER_PCC计量草案，6项计量依据仍待补。
- SOC下限90、上限20阻止保存，定位聚焦SOC上限。改成20/90后保存模拟工程版本R16。
- 模拟演示：零馈上限0、进网目标25kW、PV限值80%、储能充放电站级上限各500kW。均为演示计划值，不是厂家推荐或批准定值；未补充/伪造厂家依据。
- 计量问题可回到步骤08。现场与离线环境未带入模拟勾选/参数；回到模拟仍保留500kW草案。
