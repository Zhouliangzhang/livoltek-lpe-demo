# M1 步骤05：电气连接实现说明

依据新设计顺序，在结构与设备身份之后录入端口级电气连接。两端先选择对象再选端口；单一兼容端口自动选中。引用现有端口定义，不自动创造缺失端口。按 AC/DC、电压、相制、方向及重复连接筛选，但这不替代 EPC 设计或厂家接口批准。

回路必须引用步骤03的馈线、断路器或已有回路编号的结构。型号/身份提示取自步骤04当前环境记录。图纸、厂家依据可以暂缺，始终显示待补/待核验。填写引用不会自动批准。

保存到 project.electrical_drafts，离线、模拟、现场分别记录；既有 edges 保留为共享规划参考。原连接修订通过 base_edge_id 关联，同环境仅允许一条修订。步骤05的列表和只读图使用该环境有效连接集。本阶段未将草案发布为已批准部署基线或发送给设备；后续配置基线发布需要显式采用该环境有效连接集。

图在作业区下方按回路分组，显示对象、端口名称与编号；跨行同对象只是引用。仅按钮缩放，禁止拖动、编辑和手工连线，滚轮用于页面上下滚动。保存后立即重建。

验证覆盖：端口存在性、域/方向/电压相制兼容、重复连接、回路有效性、状态与环境枚举；浏览器覆盖保存后重载、环境隔离、必填提示及图上滚动。实际 CI-20 项目以模拟环境修订 PV_01 支路记录，原接线保留，EPC 与厂家依据均保持待确认。
