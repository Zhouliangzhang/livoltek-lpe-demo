# M1 步骤06通信与控制关系（2026-11-08）

按顺序接入步骤06。复用已有设备、工程总线和通信/控制端口，起终点先设备后端口，唯一兼容端口自动选择。通信与逻辑指令分层；不将逻辑控制端口作为线缆，不将路径存在等同于在线、驱动兼容或控制授权。

当前项目单台 iEMS：零馈表 RS485 计量路径、光伏 RS485 工程总线、工业交换机至储能以太网，以及逐台 PV/BESS 设定值逻辑关系。卡片路径从当前环境图搜索生成，展示代表设备路径；全组逐台关系在列表中记录。跨协议须显式网关，路径搜索只检验图可达性，不验证网关转发或协议。

新增/修订记录存入 project.network_drafts，按 OFFLINE/SIMULATION/REAL 隔离。base_edge_id 引用保留的原规划边；未发布到部署基线，未改变 legacy edges。后续通信配置与基线发布应显式采用该环境有效关系集。缺少厂家端口、线缆、点表、固件、驱动及控制权限依据始终 PENDING，填写引用不自动批准。
