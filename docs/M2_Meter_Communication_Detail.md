# 零馈表与 iEMS 通信专项点检（METER-COMM-1）

基于清单保存时的 M1 快照显示两端逻辑端口、型号、SN、固件与适用接口域的通信参数，计划值与现场值分列。逻辑端口不等于实物端子，文档引用不代表批准。

五项：端口对应、线缆线序屏蔽、通信参数、设备识别、计量数据。沿用两类旧检查项，新增 detail_key 区分五项独立记录；保留原综合反馈，不自动视作逐项完成。每项保留实际值、说明、照片和版本。未知厂家要求明确列出，禁止通过。读取身份与计量数据前需记录现场条件与方法引用；此引用为人工声明，不是系统审批许可，也不触发设备操作。

验证：38 项后端测试；2 项页面测试；构建通过。包括逐项记录持久化、互不覆盖、接口参数过滤、读取前提校验、异常显示、原照片流程回归。
