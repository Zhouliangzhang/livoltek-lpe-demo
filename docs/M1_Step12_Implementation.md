# M1 步骤12：继续调试

## 定位与操作

M1 和 M2 是同一工作台、同一工程师的连续工作，不设置人工交接或单独封存手续。

步骤12自动沿用最新冻结基线及对应读回记录。工程师点击“继续调试”，后台保存不可变配置引用，必要时更新 M2 模型依据并进入调试。M2 顶部仅展示紧凑的配置状态栏，待办和原始证据按需展开。新建会话自动带入 M1 操作人及配置依据说明；本次验证范围仍需确认。

离线仅保存准备记录，不执行测试。模拟和现场分别保存、查询；当前真实 iEMS 未接入，现场控制不能放行。

## 证据与边界

引用记录包含冻结基线、哈希、范围、身份、端口、连接、参数、版本、下发任务与原始读回、未完成项、责任方。相同根因在界面合并展示，原始问题不删除。

M2 建会话重新核验项目、环境、版本、控制器和通信路径，保存引用快照。M1 新版本使旧依据过期，历史仍可追溯，不能覆盖原会话。配置读回一致不产生调试或 SAT 通过结论。继承本次未批准依据的控制测试在界面与服务端保持阻断。
