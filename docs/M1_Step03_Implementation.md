# M1 步骤03：电气结构与只读归属图

步骤03继承步骤02的系统范围、控制域/PCC及项目依据引用。支持新增或编辑PCC、变压器区、变压器、MV/LV母线、汇流柜、馈线、断路器；汇流柜用母线对象和结构角色表达，不引入虚构SN。

结构记录包含稳定编号、名称、所属结构、自动推导的变压器区、回路编号、设计电压等级、相制、用途、EPC图纸引用及厂家依据。馈线与断路器要求回路编号；避免重复编号、归属循环；移动分支同步更新后代区域归属。保存产生项目新版本，保留原版本。

图纸或厂家资料缺失保持待补充；录入引用也保持待核验，不直接成为批准。后端拒绝把新结构工程记录直接标记APPROVED。旧规划样例中的额定值保留原假设标注。

拓扑按共同上级自动分组，父对象在组内为上级引用；虚线只表示归属，不冒充电气接线。使用X6只读模式，关闭拖拽、平移和滚轮缩放，保留按钮缩放。滚轮用于浏览页面。

滚动修复：将HTML根滚动区域的高度明确限制在视口，正文及应用内容自然增长；移除横向溢出，保持文档滚动。端到端测试在实际Edge浏览器引擎中将鼠标停在结构图上，验证向下及向上滚轮均改变页面位置。

验证：117项后端测试通过；M1前两步和步骤03页面测试通过，分组图调整后再次通过步骤03测试；生产构建通过。CI-20主进线QF_MAIN已保存规划回路编号，形成R8，图纸、相制与厂家依据保持待确认。
