# M2 系统联动测试（2026-11-08）

## 范围

M2 顶部新增系统联动区，保留下面的光储逐台测试及零馈表测试。由保存的 M1 模型识别唯一 iEMS、唯一零馈表及光伏/储能设备，检查计量连接、同一控制器的通信路径和控制关系。

本版本为独立的确定性稳态模拟器，无现场协议适配或控制下发。逐台指令及功率反馈是合成值，不代表设备性能验证、动态零馈能力或现场 SAT。每次场景独立运行，不继承单机测试的通过结论。

## 场景与证据

| 场景 | CI-20 演练结果 |
|---|---|
| 光伏富余、储能吸收 | 负载 800 + 充电 300 − PV 1075 = 购电 25 kW |
| 充电受限、光伏限功率 | 负载 800 − PV 775 = 购电 25 kW |
| 负载增加、储能放电 | 负载 1600 − PV 900 − 放电 675 = 购电 25 kW |
| 计量过期 | 标识具体电表，阻断本次指令生成，无功率反馈结果 |
| 光伏拒绝限功率 | 可选具体光伏设备；CI-20 单台维持 125 而非 77.5 kW，导致馈网 22.5 kW |
| 储能拒绝充电 | 可选具体储能设备；单台未吸收分配的 30 kW，导致馈网 5 kW |

上述数字都是测试样例：购电目标 25 ± 1 kW、光伏每台可用功率上限 125 kW、储能充电每台 30 kW / 放电每台 70 kW。没有把 M1 待确认值冒充批准配置。页面“演练参数与验证边界”列出本次参数。充电受限场景以可用充电容量为零表达边界，不模拟真实 SOC / BMS。

功率符号：并网点正数购电、负数馈网；储能逐台指令正数充电、负数放电。比较指令与合成反馈，并通过负载 + 充电 − 光伏 − 放电核对目标。正常场景仅在演练目标容差内且无设备异常时显示“模拟联动通过”。

## 异常与记录

- 具体设备、异常码、注入原因、M1 定位、厂家协同草稿入口。
- 逐台指令/反馈表支持仅看异常；可查看 M1 端口路径及逻辑控制边。
- 每次不可变结果保存于 SQLite，关联基线摘要、配置读回记录、场景与时间。历史选择仅查看旧记录。
- 缺少控制域、通信路径或控制边，显示 BLOCKED，无设备指令。
- 必须先完成当前 M1 配置模拟下发及读回一致。模型变化、读回不一致或 REAL 请求在后端拒绝。
- 真实模式不展示模拟结果或模拟通过数；未接入真实 iEMS 前，执行禁用。
- 故障原因是主动注入的已知原因，不是从现场日志推断的根因。厂家协同仍为本地草稿，不自动发送。

## 验证及下一步

44 项后端测试、3 项浏览器流程测试、生产构建通过。新增测试覆盖正常功率平衡、计量阻断、设备异常定位、模型变化、真实请求无副作用及历史结果隔离。

真实接入仍需厂家提供适用点表、计量符号与刷新周期、iEMS 分配优先级、光伏限功率与储能充放电权限/边界、响应时间、允许馈网瞬态、失联及恢复策略。现场控制程序应运行于 iEMS，而非浏览器；本模拟器没有实现时间序列动态模型。
