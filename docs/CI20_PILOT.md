- [HXEM100 手册](https://info-support.livoltek.com/2-Product-Material/ProductFiles/others/User%20Manual_HXEM100.pdf)：单机最多十台逆变器/储能柜，支持主从管理。采用主控 + PV 分组控制器 + BESS 分组控制器的候选架构。级联拓扑、实际固件及混合设备协议仍须厂家确认，未将二十台设备假定为一台控制器可直接接入。

- [LIVOLTEK 肯尼亚工厂案例](https://www.livoltek.com/case/1-1mw-1mwh-grid-tied-solar-storage-project-at-a-plastic-production-factory-in-kenya/)：公开案例使用相同产品系列，是本样板工商业并网光储组合的参考，并非本项目的设计依据。

## 系统组成

| 部分 | 本例配置 | 数据性质 |
|---|---|---|
| 光伏 | 10 × GT3-125K-1；1.25 MW AC | 型号额定值来自公开资料 |
| PV 阵列 | 每台逆变器对应一个 150 kWp 聚合边界，共 1.5 MWp | 演示假设；组件、串并联、MPPT 分配尚未设计 |
| 储能 | 10 × BES-P125X261E；1.25 MW / 2.612 MWh | 公开型号额定值；现场交付版本待核 |
| AC 汇流柜 | 光伏两面、储能两面，每柜五回路，1250 A 候选 | EPC 选型假设 |
| 支路开关 | 20 路 250 AF 框架候选 | AF 不等于整定值；未指定保护整定或分断能力 |
| 配电边界 | 单台区；既有 2500 kVA 变压器低压端；总进线 4000 AF；母线 5000 A；负载馈线 3200 AF | 全部为容量/结构假设，待短路、温升、敷设、选择性及电网条件核算 |
| 零馈计量 | PCC 三相 CT 组、外置 CT 式电表、电压取样熔断器 | 表型号、4000/5 A 变比候选、精度、方向及外表兼容性待核；也需评估 iEMS 内置计量方案 |
| 控制通信 | 三台 HXEM100 候选、24口工业交换机、PV RS485 逻辑总线、BESS Ethernet、逻辑控制关系 | 寄存器、地址、终端、屏蔽、超时、主从权限待核；逻辑控制线不是额外物理电缆 |
| 辅助系统 | 控制柜 UPS 与电源开关、工厂负载聚合边界 | 电源相制/电压转换、UPS 容量、接地、消防及急停硬接线未作详细设计 |

主路径：变压器低压端 → 总进线开关 → CT 穿心计量位置 → PCC → 主母线。主母线分出四路光储汇流、工厂负载及辅助电源。每面光储柜经五个独立支路开关接五台设备。CT 次级至电表，电表至主控，主控经分组控制器协调光储。

国家 ZA、400 V/50 Hz、负载 2 MW 包络、进口功率上限 2 MW、零馈目标 0 kW 与 25 kW 进口裕量均为本样板假设，不是当地并网批准条件。最大负载与储能满功率充电不能无约束叠加，需进口限额和现场功率因数等校核。柜体额定值不构成施工建议。

IP 地址采用文档示例网段 192.0.2.0/24；不能当作现场网络配置直接部署。计划值与实际值分列，所有 SN、固件、实际安装位置、实际设置及批准值留空。拟安装机位另存为 planned_location，避免冒充现场调查结果。

## 试跑结果

- 数据：75 对象、27 资产、240 端口、120 连接、54 个模拟功率映射。原始 Schema 未改动。
- 本地保存 R1，重新读取一致；L3 可查看第十台储能，L5 可按 iEMS 筛选，L6 可定位其缺失固件字段。
- L6 实际页面：452 项缺失信息、0 项已检出设置冲突、297 项待厂家确认。数量按字段和规则计数，不是 749 个相互独立的工程缺陷；当前规则也没有覆盖所有电气设计风险。
- M2 实际生成 9 个工作包，全部 BLOCKED。涵盖储能资料、计量接口、第三方接口、边界和上电门禁；仍为通用模板，未细化为二十台设备逐台施工工序。
- 正常模拟：PV 1250 + 电网进口 25 = 负载 800 + 储能充电 475 kW。
- 反向模拟：电网进口 1100 + 储能放电 500 = 负载 1600 kW。两种情景均按主母线及四面汇流柜逐点验证功率平衡；忽略转换/线路损耗，辅助负载计入总负载。
- 遥测过期/缺测时无有效功率流；模拟量不会写入现场实际设置。没有做动态防逆流、SOC 积分、负载突降或保护动作仿真。
- 软件正式发布门禁保持禁止。流程可走通，但现场运行条件和工程资料远未齐备。

## 暴露的后续工作

1. 原试跑发现 75 个对象集中显示时拓扑过密；现已改为主配电、光伏汇流、储能汇流、通信控制四区自动布局，详见 GROUPED_TOPOLOGY.md。
2. L6 字段级待办数量较大，需按设备/同类参数聚合；还需专门的控制器容量、计量极性、失联和零馈策略规则。
3. M2 需要受控的逐台设备模板、制造商适用版本、EPC 安装条件和现场证据；不能通过虚填批准状态来消除阻塞。
4. 采购 BOM、短路/保护/电缆计算、消防及接地边界、正式协议点表、CT 验证和投运测试都未完成。

## 重现

在仓库目录运行 `.venv/Scripts/python.exe scripts/build_ci20_pilot.py` 可重建 examples/ci20-pilot.json。启动本地服务器后，加 `--install` 会通过现有 API 新建项目；项目已存在时返回版本冲突，不覆盖既有版本。浏览器项目下拉框选择“CI-20 工厂光储”。验证记录见 ci20-validation.json。
