# M1 步骤01–02：项目上下文与系统边界

实现范围：M1 前两个顺序步骤。步骤03–12保留现有工程编辑入口，尚未完成按新设计重构。

- 步骤01：区分离线编制、模拟和现场。操作人及编制角色按项目/环境保存在本机，不等同于账号鉴权。现场接口未接入，不能宣称身份核验或权限通过。现场调试入口保持阻断。
- 步骤02：项目定义、时区、能源组成、运行方式、控制域/PCC/iEMS规划对象、范围说明及资料引用。支持多个控制域；没有实物对象可暂存草案，在后续步骤补充。
- 系统边界进入既有项目版本保存，批准状态只能是DRAFT。后端验证对象类型/引用、域编号和时区，基线供应方schema保持不变，由工作台增加扩展。
- 框架表达规划关系，随能源组成调整；不写入设备或连线，不自动选开关规格。厂家依据和EPC现场依据明确待确认。
- 离线、现场不读取模拟功率流；模拟标识不作为真实SN。编制模型可作为不同环境的草案，配置执行与测试环境仍独立。

页面验证已执行：缺少操作人提示、步骤顺序、保存及刷新恢复、环境切换、现场未连接提示及调试阻断。CI-20边界保存为R7演示草案，现有交接包保持原版本。

限制：尚无真实控制器接入、用户身份服务或厂家资料核验接口；本次不实现真实写入。时区目前提供界面列出的7项选项。
