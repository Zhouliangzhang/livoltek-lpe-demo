# M2 零馈表反馈失效演练

仅为模拟，不下发现场控制，不形成 SAT 结论。厂家依据状态为 PENDING。

## 演示流程

在 M1 完成当前模型模拟下发、读回一致核对；进入 M2，选择“负载突变”和“零馈表通信中断”，保持默认恢复选项后运行动态模拟。

- 10 秒：注入通信中断；计量值为空，无效反馈不参与控制计算。越界场景则注入并拒用 1×10⁹ kW 合成值。
- 默认 12 秒：演练检测时间到，退出零馈闭环，光伏与储能目标均为零。模型假设设备通信正常并接受指令，按假设斜率响应；瞬态馈网仍展示。
- 28 秒解除故障，默认 29 秒收到新鲜有效样本；继续保持降级并观察 3 秒。
- 默认 32 秒：恢复依据有效反馈的分配，设备按演练斜率渐进响应。
- CI-20 负载突变样例在 50.5 秒完成模拟稳定观察；末点购电模型功率为 25 kW。这不是厂家性能保证。
- 选择持续故障时，末点保持反馈不可用，不显示恢复成功。

蓝色计量曲线在无效期间断开，绿色为模型真值，仅用于解释演练，绝不作为失联期间控制器的隐藏输入。对照模拟同样失去反馈，只保持原指令。馈网时间、电量及末点功率全部是模型计算值；无反馈时不能确认现场馈网。

待厂家确认：超时与数据异常判据、光伏降零能力、储能零功率策略、指令拒绝和通信失联处置、BMS / SOC 约束、保护联锁、恢复权限与斜率。当前模型没有这些现场验证能力。
