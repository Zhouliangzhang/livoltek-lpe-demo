# 步骤04 光伏通信与身份实施

用户批准设计：PCC验证为前置；按通信路径逐台读取身份、能力、状态、质量，同型号/固件/驱动适用范围合并主题；未知固件仅归待确认组，不能当作适配已批准。

实施：新增独立pv_communication模块与页面，引用冻结M1及当前meter_session的PCC证据。显式确认并冻结全体光伏只读范围，不默默扩大原计量范围、不允许排除异常设备。运行保存逐台证据、路径、能力和模拟源；模拟与现场隔离。复测保留旧记录，PCC重测或模型变化使旧光伏记录失效。真实适配器尚未接入，所有功率控制始终锁定。

测试先行：PCC前置、逐台结果、故障不中断他台、分组、无映射/重复SN、缺能力、幂等、PCC失效、真实模式阻断；前端分组展开与异常定位；构建与真实页面截图。

完成验证：后端全量 76 项通过；前端构建通过；零馈表流程回归和新增光伏页面流程通过。页面流程覆盖 PCC 阻断、PV_03 异常置顶及 M1 定位、正常逐台复测、刷新保留及现场/模拟隔离。CI-20 实际页面已演示 9 正常 + 1 异常及 10 台正常模拟。

当前限制：真实 iEMS 驱动未接入，不产生现场结果；型号/固件适配、点表、刷新判据、失联行为及替代能力证据仍需厂家批准。SN、固件、安装位置缺失保留 EPC 待补项。模拟身份不回写 M1，模拟通过不代表现场通过。
