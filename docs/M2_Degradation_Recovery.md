# M2 控制降级与恢复演练（2026-11-08）

## 本次增加

动态联动模拟支持储能拒充和储能通信中断后的降级、恢复与对照曲线。已有时间序列和历史记录保持兼容，新增记录版本为 M2-DYNAMIC-2。

页面选择故障设备后，可启用降级重分配，选择故障持续或 28 秒恢复。降级结果、恢复过程和历史故障分别显示；模拟恢复不覆盖故障事件，也不计为现场 SAT。

## 演练策略（全部待厂家确认）

1. 10 秒注入故障；经过“计量延迟 + 1 秒”的固定演练检测窗口后退出目标设备。此处是预设检测时序，不是接入现场日志的诊断算法。
2. 目标设备分配权重归零，其余储能按各自可用充放电容量分配；剩余富余功率通过降低光伏目标处理。
3. 故障持续时保留退出状态。若并网点最后 3 秒维持演练目标带，显示维持模拟降级，不显示设备已恢复。
4. 若选择恢复，28 秒合成通信/充电许可恢复，继续保持退出；经过计量延迟和 3 秒稳定观察后开始 5 秒渐进恢复权重。
5. 完成渐进接入且并网点最后 3 秒保持目标带时显示模拟恢复，否则显示观察窗内未恢复。不能保证所有台数、延迟、负载或故障组合都在 40 秒内恢复。

默认 1 秒计量延迟对应：10 秒故障 → 12 秒降级 → 28 秒恢复待确认 → 32 秒渐进接入 → 37 秒接入完成。

## 失联数据边界

失联期间 `feedback` 和 `sent_command` 为 null。页面显示“无新鲜反馈”“无指令送达确认”；`actual` 为合成被控对象功率，不能作为实测值。

本次仅假设失联储能本地进入 0 kW 待机；真实设备可能保持原指令或采用其他策略，必须由厂家确认。独立模拟器按该假设计算被控对象及计量，不能证明未知失联行为下的安全性。真实控制器应基于受控失联策略、有效 PCC 计量、权限和联锁运行。

厂家待确认项在页面明确列出：检测门槛、重分配优先级、失联本地行为、重连授权、稳定观察条件与恢复斜率。

## 同条件对照

启用降级时后端同时计算相同扰动、设备及故障持续时间下“不启用降级”的对照序列。绘图和累计馈网指标都来自计算结果，不强制将降级显示为更优。

CI-20、储能受限、BESS_03 持续失联、1 秒计量延迟的演练：未降级末点馈网 5 kW；启用降级末点购电 25 kW，可分配储能 9 台。累计模拟馈网时间为 15.5 秒与 3.5 秒。

若同一故障在 28 秒解除，两个场景累计馈网时间均为 3.5 秒；降级仍更准确保持故障期间的目标分配。不能宣传每个场景都缩短累计馈网时间。

## 验证

新增 3 个后端场景测试覆盖拒充/失联的退出分配、恢复观察、逐渐接入、持续故障维持降级、反馈空值和同条件对照。浏览器测试验证降级时间线、失联标识、恢复前后设备状态及现场隔离，并回归动态曲线流程。

真实 iEMS 尚未接入，REAL 请求拒绝且不写入结果；真实模式不显示模拟曲线或恢复结论。
