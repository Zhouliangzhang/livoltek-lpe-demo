延续用户确认的顺序：步骤03–08当前且完整满足后，独立确认整站模拟控制范围；真实适配器未接入时禁止真实写入。

1. 新建 zero_export.py：按冻结M1范围加载表计、iEMS、PV/BESS及步骤05能力；建立独立范围与幂等运行ID，前置重测使结果失效。
2. 合成闭环验证充电吸收/光伏限功率、放电配合、退出恢复；逐点保存功率平衡和设备目标/反馈，质量失效不使用旧读数。
3. 新建 ZeroExport.tsx：四阶段、系统曲线、逐台证据、异常定位与厂家协同草稿；模拟与现场隔离。
4. 后端测试正常功率平衡、边界、前置及真实锁、反馈失效、拒令、恢复告警；页面测试和实际项目截图。

演练目标为购电10kW，稳定末3点±2kW且不得馈网。所有阈值、功率策略及退出规程均为合成演练参数，厂家依据待确认，不构成现场SAT。

## 明确限制
这是快速同步计算的独立模拟器，不连接任何现场设备，不代表真实iEMS拥有本控制算法。合成负载切换用于建立两个稳态工况，过渡期间可能出现短时馈网；本步仅按明确标注的演练稳态窗口判定，动态响应留给步骤10。SOC55%、可用功率、符号、阈值和退出策略都是演练假设，现场依据待厂家确认。真实适配器、现场授权与批准规程未接入前，现场结果为空且写操作锁定。
