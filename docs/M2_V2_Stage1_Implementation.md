# M2 V2 第一阶段实现说明

依据：LIVOLTEK_M2_Design_V2.0_Review。范围为三步骤、检查主题、具体对象记录和独立异常入口。

- 电气 / 通信 / 控制，每步四个主题；主题中按设备或回路选择记录，通信接线与参数记录归入同一连接对象。
- 共用指引按型号版本、接口域及检查方法分组，不合并实际结果；照片及记录沿用原有持久化接口和不可变记录 ID。
- 异常区从本清单全部历史 FAIL 记录汇总，最新状态改为 PENDING 后显示待复核，不自动移除。此阶段尚未实现独立问题责任分派、审核关闭与跨清单继承。
- 每个清单记住当前步骤、主题、对象；定位 M1 再返回 M2 可继续原对象。
- 旧工作包与照片只读保留，退出新作业主流程。辅助通信总图仍可查看。
- 本次为展示重构：185 条原始检查实例未删除或重新解释，模拟量 CT 连接归电气计量主题；旧实例的措辞、接地适用性等后续由受控生成规则版本修订，不冒充厂家已确认要求。
- 不包括厂家依据审批、动态控制验证、施工进度、异常审批闭环。现场点检不构成允许上电或系统可运行结论。

验证：前端构建；后端回归；页面测试覆盖逐台反馈独立、照片持久化、异常转待确认仍保留、M1 定位返回、旧历史只读及新旧证据隔离。
