# M1 步骤04实现与验证（2026-11-08）

按已批准的新 M1 设计接入步骤04，保留现有25台规划设备，按型号及记录固件分组。默认不展开详情，点击设备后录入；所属结构和回路引用步骤03，回路按所选结构过滤。

- LIVOLTEK：支持扫描枪/粘贴 JSON 产品标识，精确匹配项目已有型号及厂家资料版本；未知或不匹配型号拒绝套用。当前不支持摄像头扫码、厂家在线查询或签名离线包核验。未将任何资料标为厂家批准。
- 二维码最小格式：`{"manufacturer":"LIVOLTEK","model":"GT3-125K-1","sn":"设备SN"}`。可选 firmware 是出厂信息，不自动填入当前固件。模拟示例携带 simulation=true 及 SIM- 前缀，非模拟环境拒收。
- 第三方：零馈表、交换机、自定义 DRAFT-1 字段引导模板；逐台录入厂家、型号、资料引用和现场信息。模板不是驱动兼容证明。候选型号信息保存在本环境记录，尚未发布到共享型号主数据。
- 身份记录按 OFFLINE/SIMULATION/REAL 分开保存在 node.attributes.identity_records；每次保存追加 identity_history，项目修订版本同步保留。模拟和离线记录不覆盖 canonical 实物资产。现场手录资产保持 PENDING，无现场接口连接或验证声明。
- 同环境 SN 唯一性、有效结构/回路引用、来源环境和待确认状态由服务器验证；SN 变更要求 UI 填写原因。该步骤可保存缺项规划记录，不构成现场部署放行。
- 未新增设备发现/新资产创建入口，现有项目设备清单沿用 M1 工程模型；后续新增设备仍可由现有作业区登记。

验证：新增后台身份约束测试；浏览器测试覆盖扫码、出厂与当前固件分离、保存后重载、模拟/现场隔离、第三方手录。实际 Edge 完成 PV_01 与 METER_PCC 两条模拟记录，形成 R9/R10；未录入真实身份或下发设备。
