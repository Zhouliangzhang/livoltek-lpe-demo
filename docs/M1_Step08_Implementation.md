# M1 步骤08：PCC 计量设置

依据：iEMS_M1_System_Modeling_Configuration_Design.md 第11节。界面按关联计量对象、CT/PT、功率换算、数据质量与依据的顺序组织。

## 已实现
- 自动列出 M1 电表及 PCC；只有一个 PCC 时带入候选，多个 PCC 要求明确选择。读取当前环境步骤06有效通信路径及 CT 信号路径，不从型号名称推断额定值。
- CT/PT 区分直接接入与外置互感器。铭牌一次/二次额定值、计算比值与仪表内部倍率分列；输入读数侧别、总有功功率字段、厂家原始单位、符号与驱动数值缩放。
- 内部固定采用购电正、送电负及 kW。一次侧读数仅应用驱动缩放、单位和符号转换；二次侧另乘 CT 比和 PT 比。实时显示公式，不产生实测值。
- 缺项按 EPC 补充、厂家确认列示并定位字段。冲突包括重复 PCC/表映射、无效对象、非正或非有限数值、无效单位/方向、直接接入与外置额定值共存、一次侧仪表倍率与铭牌比值不符、过期判定短于刷新周期。
- 草案允许保存缺项，但冲突阻止保存。页面进入运行策略前检查缺项和未保存编辑。数据按 OFFLINE/SIMULATION/REAL 隔离，项目历史版本保留。设备身份、型号、端口或直接通信路径变化要求重新核对。
- 数据质量填写采样时间来源、刷新周期、过期判定与质量字段/规则。空缺不自动生成阈值，未知不补零。
