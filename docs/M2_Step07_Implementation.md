# 步骤07 光伏限功率控制测试实施

按用户要求实现顺序：控制前核验→逐台指令确认→实际功率响应→撤销测试并读回恢复。复用M1型号/固件分组、逐台证据与定位。当前未接真实iEMS，仅允许独立合成演练，厂家批准规程、控制租约及现场权限缺失时现场控制保持锁定。

- [x] 后端：核验03–06当前证据及读回无差异；明确新建PV控制演练范围，不继承只读权限。逐台建命令ID，保存原限值、目标、确认、功率轨迹与恢复读回；异常停止后续设备，所有权丢失不再发新指令。
- [x] 页面：前置与批准依据卡、同型号主题、逐台阶段结果与功率曲线，异常定位及厂家协同草稿。
- [x] 验证：拒令/超时、确认不等于功率响应、光照不足条件未满足、恢复失败、权限丢失、幂等与刷新、现场隔离；实际页面截图。

演练夹具独立定义初始限值125kW、初始功率80kW、可用100kW、测试限值50kW及容差/时限，全部不是厂家规格。恢复核对原限值及当时可用功率，不将固定恢复功率要求用于真实现场。未确认恢复要保留告警，不自动进入下一台。不自动绕过BMS或安全联锁，不执行真实设备I/O。

验证：后端全量86项通过；追加绑定iEMS控制连接缺失门禁测试，控制专项4项通过；构建及控制页面端到端测试通过。实际CI-20 R6演示正常10台、PV_03功率未响应（2台完成、1台异常、7台未启动）、恢复未确认锁定与独立模拟恢复复核。

当前为独立合成模拟执行器，不是真实iEMS内嵌测试引擎。所有命令及曲线明确SIMULATOR；真实入口/API拒绝控制，缺厂家依据保留PENDING。恢复复核单独存证，原失败不改写，同运行ID不重复生成动作。
