# 零馈表失联与光伏拒令复合演练

模拟专用，不发送硬件命令或厂家消息，不形成现场 SAT 结论。厂家依据 PENDING。

选择“零馈表失联 + 光伏拒绝限功率”，指定 PV 设备、储能余量及故障是否恢复。10 秒后采用明确标注的低负载 20 kW 压力场景。拒令光伏保持故障前输出，其他光伏接受降零指令。储能依据仍可获得的延迟设备反馈尝试吸收拒令光伏输出，并受合成可用充电能力限制，不使用失联期间模型 PCC 真值或估计负载继续闭环。

CI-20 默认充电受限（5 kW/台）且持续故障：PV_03 输出 107.5 kW，储能合计充电 50 kW，负载 20 kW，末点模型馈网 37.5 kW；与拒令输出相比的充电能力缺口为 57.5 kW。这两个数字含义不同。充电余量充足（30 kW/台）时，储能尝试吸收全部拒令输出，模型可能无馈网，但由于 PCC 反馈仍缺失，严重告警保持，不能宣告现场零馈安全。

恢复选项在 28 秒解除两项注入异常；计量新鲜样本恢复后观察 3 秒，才恢复闭环。结果保留历史严重告警。长期储能能量余量、SOC、BMS、指令拒绝处置、超时判据、保护联锁与恢复授权均待厂家确认，当前未建模。

告警分别展示当前计量是否可用、设备反馈、吸收能力缺口、所选时刻及末点的模型馈网功率。厂家协同按钮将项目关联下的记录 ID、两台故障对象、模拟结果与待确认项带入 M4 本地意见草稿；不会自动发送。现场停机或隔离须依据批准程序由现场人员处理，本演练不自动跳闸。
