# M4 故障受理与引导诊断演练

本阶段实现零馈表失联的故障受理、基线引用、顺序诊断与本地厂家协同草稿。维修、复测、服务关闭仍为后续阶段，未生成虚假完成状态。

## 操作
1. 打开 http://127.0.0.1:8000/，选择 CI-20 项目、模拟 iEMS、M4 现场服务。
2. 选择同环境 M3 交接包及零馈表，填写报障人、现场当地故障时间、故障现象，确认只读范围。
3. 选择独立模拟场景，建立服务单。场景是合成故障，不改写 M1。
4. 依次执行保全证据、供电与影响范围、通信路径、配置及后续变化、根因与处理分工。
5. 查看每项原始证据、诊断分类与处理建议，生成厂家协同草稿。草稿未发送到外部服务系统。

## 基线与结果规则
- 服务单冻结 M3 基线、交接哈希、受理时保存模型及版本、后续版本清单、设备身份、端口路径、未完成项与历史证据引用。
- 保存模型差异与实际设备状态分开；没有保存差异不代表现场未变更。受理后工程变化会阻止沿用旧上下文继续诊断。
- 配置、安装、运行条件、疑似产品故障、证据不足分别分类。产品质量和保修不由模拟诊断自动判定。
- 厂家依据待确认；真实 iEMS 未接入，现场环境不提供模拟数据或模拟结论。
- 本次实际浏览器演练：交接包 f07bf97c，R17，服务单 8323e36e；五项诊断记录，地址不匹配模拟结论，包含五项证据的协同草稿。切换现场环境后不显示该模拟服务单；返回模拟环境可以重新读取。
