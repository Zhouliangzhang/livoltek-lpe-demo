# 步骤08 储能充放电控制实施计划

按用户设计实施。每台按充电→恢复→放电→恢复顺序；每个方向单独保存SOC、BMS允许、实时边界、指令回执、功率响应、恢复。条件不足方向CONDITION/未测试，不能因另一方向通过而全台通过。动作异常或恢复不明停止后续动作；条件不足可继续其他允许方向/设备。

- [x] 测试：前置03–07及基线失效；SOC/BMS方向限制；双向分别判据；边界降低中止；回执与响应区分；恢复告警、幂等、现场隔离。
- [x] backend/bess_control.py：独立模拟执行器，按方向合成新鲜反馈并与步骤05的限制取交集，不能用额定值推断可用容量；步进目标不超边界，单方向结束核验原功率和模式。
- [x] 前端：同型号分组、充电和放电独立结果卡、正负功率曲线、条件/异常定位、厂家依据待确认、历史记录。
- [x] 构建/测试/实际CI-20演示截图，保存并同步。

演练参数仅用于夹具：SOC55%、允许10–90%、充电上限80kW/放电100kW、测试幅值30kW（取实时边界较小者）、初态待机0kW。真实厂家依据未提供，不代表适用规格；控制器不能覆盖BMS。本实现无真实硬件I/O，真实入口锁定。

验证：后端全量90项通过；追加目标按较小边界限制与双方向独立采样证据测试，储能控制专项4项通过；储能与光伏页面端到端2项通过；构建通过。实际CI-20演示10台双向满足、BESS_03 SOC不足（充电满足/放电未测试）、充电恢复失败阻断放电与后续7台、独立恢复复核及新一轮正常测试。

真实iEMS执行器仍未接入，无现场指令下发。所有边界、SOC、响应轨迹及恢复均为独立SIM夹具，厂家规程与现场权限仍PENDING。控制前引用03–07同一基线有效证据，步骤05方向限制不被本步擅自扩大；每个方向保存新的合成采样序号与逐点边界。
