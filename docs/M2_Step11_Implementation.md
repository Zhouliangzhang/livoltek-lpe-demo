# Step11 降级与恢复实现计划

- 复用步骤03–10证据链，仅在当前三类动态测试均满足并恢复后开放独立模拟。
- 三类场景：PCC表失联采用明确标注的合成保守退出（PV限0/BESS归零，零馈不可判定）；PV拒令按已知实际功率重新分配其它PV/BESS；BESS拒充移除该台容量、不覆盖BMS保护。
- 每秒保留质量、指令确认、功率与告警状态。恢复条件包括反馈有效、全部指令可执行、设备响应及PCC稳定连续5点；复发立即清零。退出原状态也须验证，才能解除告警。
- UI展示三场景、状态轨迹、功率曲线、具体设备问题/M1定位和厂家协同草稿；只提供模拟执行，现场依据待确认。
- 验证正常恢复、持续故障、观察期复发、恢复不符、前置失效、刷新持久化和真实控制拒绝，并截图实际页面。

演练参数（非厂家判据）：1s采样，购电10±2kW、连续5点、SOC55%、每台BESS使用步骤05边界与40kW较小值。馈网仍需明确告警；缺失反馈不能证明零馈。

## 完成与验证
- 实现独立降级测试范围、当前步骤03–10证据链、三类步骤10覆盖要求、模式隔离、幂等请求和不可改写原始记录。
- 每场景61个1s合成采样：5s触发异常、19s解除异常信号、连续5点核验有效反馈/设备响应后进入等待退出，45s起恢复原状态，原状态连续3点满足后解除告警。
- 观察期复发示例在25s重置稳定计数，29s重新观察；BESS_03在实际页面已验证该过程。持续失联和恢复限值不符均保持告警。
- 恢复端点不提供强制解除；按原运行范围生成独立合成重演证据，只有稳定和退出恢复均满足才解除模拟告警。复核失败时保留告警，成功也不改写原失败结果。
- 后端全套102项通过（保留原有降级回归测试，新增步骤11独立测试文件）；步骤10/11两项浏览器用例通过；最终前端构建通过。
- 实际CI-20 R6页面已验证三类异常、BESS_03复发计数清零、持续失联及复核失败、刷新持久化、复核成功和三场景最终恢复。截图位于当前Codex目录outputs/m2-step11-*.png。

## 实施边界
执行器为快速同步计算的独立合成模拟器，非真实iEMS算法。失去PCC反馈采用PV限0/BESS归零仅为演练策略，不具备厂家批准依据；期间零馈不可判定。BMS边界、SOC、1s采样、5点稳定和3点原状态窗口均待厂家确认。正常场景注入的异常最终恢复可标为模拟测试满足，不能解释为现场SAT通过。任何真实模式请求均拒绝控制。
