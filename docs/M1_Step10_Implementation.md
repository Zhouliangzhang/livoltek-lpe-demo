# M1 步骤10：配置基线

依据：iEMS_M1_System_Modeling_Configuration_Design.md 第13节。实现仅冻结待确认工程草案，不提供批准、发布、下发或策略激活能力。

## 工作顺序
1. 选择当前环境、步骤02控制域及只读接入/部分设备/完整控制范围。部分设备只能选择步骤06已关联本iEMS的设备；完整范围自动包含全部关联目标。
2. 使用已保存工程版本计算依赖。保守纳入相连电气与通信网络、父结构、控制器、PCC与表计；目标和依赖分别展示。依赖不自动成为写入目标，范围外配置保持不变。
3. 汇总设备型号/SN/固件、厂家主数据、结构、端口连接、同环境通信、计量和策略。未知驱动/规则包版本明确为null并列待厂家确认；不使用其他环境身份记录作为模拟身份。
4. 按范围列出身份缺失/重复、控制归属、通信缺项/冲突、过期依据、完整控制的计量与策略依赖、厂家适用性和项目授权待办。只读范围不要求功率策略定值。重复待办合并展示，中文解释，按钮前往对应M1步骤。
5. 与同环境、同控制域、同范围类型上一冻结草案进行字段级增删改比较。首次内容作为新增，移出快照不代表删除现场；差异不是与现场读回比较。
6. 记录操作人及待核验授权引用，冻结不可变FROZEN_DRAFT。源模型版本及SHA-256、范围内容SHA-256、封存记录SHA-256分别保留。哈希不是审批签名。
7. 查看历史快照；修改后重新预览并生成新快照，原快照不覆盖。部署始终未放行。
