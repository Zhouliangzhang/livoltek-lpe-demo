# M2 厂家技术协同

M2 仅维护一份项目级厂家技术协同计划，按版本持续更新，不承担 EPC 施工计划或进度管理。

## 协同安排

EPC 选择设备或回路，填写联系人、期望时间、支持方式、主题和具体需求。厂家针对该需求版本确认支持时间、方式、联系人、安排说明，或要求补充资料。需求变化后旧回复保留但不再表示当前需求已确认；工程版本变化也要求重新确认。

本地演示通过操作视角切换模拟 EPC 与厂家，尚无身份认证、权限隔离或消息通知。保存不会向外部发送消息。厂家模拟确认仅涉及技术支持安排，不代表真实厂家承诺，更不代表施工审批、验收或上电许可。

## 技术指引与现场反馈

原安装工作包作为版本化技术指引保留：边界、设备就位、接地、电气接线、接口、通信及上电前检查。厂家依据缺失继续标记待确认。底层历史 plan 数据为技术指引快照，不再作为施工计划在页面展示；更新快照不会新增另一份厂家协同计划。

按设备或端口回路记录现场反馈、技术问题和补充资料；照片与对应对象及指引快照绑定。取消安装状态、施工完成率、未完成施工清单及模拟执行通过选择。旧安装记录以历史现场记录展示，不把旧完成状态转换成厂家确认。已有照片继续可读。

照片支持 PNG/JPEG，每张最多 5 MB，每条反馈最多 10 张。本地 SQLite 保存图片与记录，刷新后可恢复。反馈必须填写说明，可不附照片；厂家要求补充时可继续追加资料。过期指引快照不允许新写入，旧记录保留。

## 验证

覆盖需求必填、关联对象归属、需求版本冲突、厂家确认必须填写时间、需求或工程变化后拒绝旧版本确认。页面验证 EPC 提交、厂家模拟确认、刷新恢复、修改需求重新待确认，以及设备/回路反馈和照片上传。

CI-20 保存一条明确标记为演示的 EPC 需求：单台 iEMS 零馈控制与光储联调支持，关联 BESS_01、EMS_MASTER、METER_PCC 和 CI-074。联系人及日期均为演示占位，保持待厂家确认。
