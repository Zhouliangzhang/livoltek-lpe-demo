# M2 安装工作包流程

现有工作包按现场与系统边界、安装准备、接口与通信核对、上电前资料确认排序，并优先满足模板前置依赖。CI-20 R6 共 9 个工作包，分别为 2、1、5、1 项。此为当前模板覆盖范围，尚不是完整设备就位、接线、调试施工 SOP。

## 缺项处理

- 待补要求以中文展示，按 EPC 补充和厂家提供分列。
- EPC 边界资料进入对应工作包的设计引用记录；现场接口映射进入接口记录。
- 厂家指导资料打开对应模板版本与来源字段；第三方接口资料定位到 L5 对应接口点表引用。
- 工程参数依据定位到 L5 对应参数的文档引用。无法匹配的要求进入技术协同草稿，不自动提交。
- 跨页面处理后可返回原工作包。项目数据修改后需保存并重新生成计划；填写引用不会自动批准模板或使任务通过。

## 验证

新增测试覆盖排序与前置依赖、中文责任分类，以及 EPC 记录、模板来源、接口点表、电缆依据四类精确定位。
实际 Edge 页面在 CI-20 R6 验证上述入口及返回流程，未填写虚构现场资料或改变批准状态。
