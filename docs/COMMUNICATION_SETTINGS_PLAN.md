# 按 L4 优化通信设置

用户已批准的逻辑：L4 决定适用参数；LIVOLTEK 型号模板自动匹配；第三方模板优先；同总线统一参数；来源不足保持待确认。

实施：
1. 新增 communication.ts：以端口和已连接通信边生成网络，只有明确的总线/交换机节点桥接，不把 iEMS 的两条 RS485 通道合并。
2. 扩展 settingsCatalog：通信使用已连接端口；多串口参数独立存储于 port.attributes.l5_settings，旧记录保留；单接口兼容旧记录。
3. 新增 CommunicationSettings：总线公共参数一次录入，设备地址单独填；型号模板精确匹配型号和版本，仅补空白计划，不覆盖现场值。无厂家数值时不猜默认值。
4. 后端按相同连接规则检查适用项及端口记录；L6 保持定位和缺项提示。
5. 测试断开连接、双总线隔离、模板补空、批量保存、地址重复与通信格式冲突；构建并打开实际页面。

## 交付记录

2026-11-07，本地 CI-20 项目保存 R5：只补充工业交换机的通信桥接标记，未修改计划/现场通信数值。页面为零馈计量 RS485、光伏 RS485、储能以太网三个网络。iEMS 的两条串口分别存储，公共参数不跨总线应用。

模板扩展在 device_models[].communication_templates 中，包含 id、version、master_data_version、domain、values、reference_doc、status。按型号主数据版本和接口匹配；LIVOLTEK 自动带出有文档引用的空白候选值，第三方手选模板补空。现有演示型号尚无厂家默认值模板，界面如实提示，提供空白字段模板。所有参数继续待厂家确认。保存时固化自动带出的值及来源，不覆盖现场记录。

端口参数保存在 ports[].attributes.l5_settings，旧单接口记录作为兼容来源；多串口不自动沿用未指定接口的旧通信值。旧资料仍保留，可在历史适用项查看。后端校验端口参数类型及版本；L6 额外检查同总线格式不一致和地址重复。当前以太网配置按设备管理；多网卡独立地址需后续进一步按接口建模。

验证：生产构建成功，完整浏览器回归 23 项通过，后端 32 项通过；另补充同总线地址重复与格式差异测试。
