# M2 通信接线技术指引

M2 主页面以零馈计量、iEMS 通信骨干、光伏通信、储能通信为四组，直接读取当前 L4 的 COMMUNICATION 连接。每条连接仅出现一次，CONTROL 逻辑关系不作为实体电缆。

每组选择具体连接后显示两端设备名称、型号版本、工程端口号、接口域；型号针脚图缺失时明确待厂家确认，工程端口号不等于实物端子或针脚。RS485 不凭 A/B 字母推定极性，不猜终端电阻或屏蔽接法；逻辑汇流节点不表示实体接线盒或现场串接顺序。

设置来自 L5，仅展示当前连接域及两端设备或端口所需参数。计划值、现场值和依据分列，可定位返回 L5。录入的来源引用不自动变为厂家批准。

只读验证分别覆盖零馈计量数据与方向、iEMS 网络链路和业务识别、光伏逐台身份与功率、储能身份/SOC/功率/告警。诊断入口、数据点、兼容固件、刷新周期及判据缺少厂家依据时仍待确认。不得据此下发控制指令或推断测试通过。

安装准备 RULE-BESS-PREP 和设备就位 INSTALL-POSITION 从新计划生成与 M2 展示中移除；相关依赖同步移除。历史计划和已有记录不删除。其余技术参考和记录保留在下方。没有重新引入上一轮已撤回的厂家协同计划表单。

验证：后端检查移除项不再生成且依赖顺序有效；前端检查通信连接完整覆盖、逻辑控制排除、RS485 不混入 IP 设置以及准确定位 L5。


## 图形接线展示

通信指引默认以 SVG 接线图展示四个分区。节点展示设备及工程端口，连线标记接口对应的线缆类别，实际规格持续待厂家确认。共享逻辑总线和交换机保持单一节点；图中分区重复出现的同名设备是同一对象，非新增设备。图形不代表真实布线路径或实物针脚。

点击连线或线缆标签后展开该连接的端点、接线要求、L5 参数和验证方法；支持键盘 Enter/空格选择及收起。图仅可查看、选择，不可拖动节点或手动改线。初始化不展开任何参数详情，减少页面文字。

测试覆盖所有 L4 通信连接恰好显示一次、逻辑控制连接不冒充电缆、默认收起、鼠标和键盘展开、收起及返回 L5 定位。实际 Edge 已验证零馈计量连接展开 8 项 RS485 参数并收起。


## 单张通信总图

最新页面以单张总图替代四分区重复节点：CT → 零馈表 → 单台 iEMS；iEMS 分别连接光伏 RS485 逻辑总线与储能通信交换机，展开当前项目的 10 台光伏和 10 台储能。按 node_id 去重绘制，所有 COMMUNICATION 连接仍来自 L4。图形布局用于当前 LV-01 光储示例，不表示实际布线距离或 RS485 星形施工接法。

选择状态改为全图唯一连接：点击另一条线切换详情，不同时展开多个分区的说明。自动测试验证单个 SVG、单台 EMS_MASTER、节点和连线集合与 L4 一致，及点击、收起、键盘选择和 L5 定位。
