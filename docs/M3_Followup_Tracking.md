# M3 遗留事项跟踪与交接修订

## 工作流程
1. 从交接包的未完成步骤、异常和待确认主题建立对象级处理项；按 EPC 补充与复测、厂家确认分组，支持筛选和定位 M1 / M2。
2. 记录处理人、资料引用和处理说明。提交 EPC 资料进入待复测；登记厂家资料仍为待厂家确认，不自动认定其适用性或批准状态。
3. 回到相应 M2 步骤重新测试并保存新报告，再关联覆盖该对象的新证据。后端核对项目、环境、步骤、对象、时序和报告有效性。缺项仍存在或步骤未满足时不能关闭；后续测试使原报告失效时显示复测已失效。
4. 选择处理后报告，生成下一版交接包。封存配置、报告、原始证据以及处理清单快照；保留父版本和完整处理历史。下载包增加 tracking.json。

## 记录与边界
- 处理记录只追加；并发修改校验最新事件，重复请求保持幂等。
- 交接版本有根版本、父版本和版本号。原包不会被更新覆盖。
- 实时处理清单与封存快照分别标识，旧版本导出保持不变。
- SIMULATION 与 REAL 隔离，模拟复测满足不代表现场验收。当前未接入厂家审批签署或真实 iEMS 验收，现场证据保留待核验；不会自动生成 SAT 通过或现场验收结论。
