# 按环节补齐必填信息

2026-11-07，依据用户最新要求取消独立 L6 运行条件检查步骤，并移除 L1 初始框架下的 L2–L6 进度概览栏。

## 页面与操作

保留 L1 项目定义和 L2–L5 作业区。点击下一环节或向前跳转时提示此前环节的必填缺项，提供定位按钮，补齐后可继续。向后查看和保存草案不受必填进度阻止；保存仍执行原有数据结构及引用校验。直接点引导式安装同样检查建模必填项。

当前必填范围：
- L1：国家、EPC、电压等级、结构分类、运行方式、能源组成。
- L2：至少有实际电气结构、已录入结构名称非空。不把模板建议的变压器/台区对象当作所有项目的强制要求。
- L3：项目能源组成对应主设备、设备名称、厂家、型号、主数据版本及资产引用。
- L4：资产至少有一条已录入连接。具体接口适用性仍需依据厂家与 EPC 资料核对，此最低要求不是完整接线验收。
- L5：适用的 EMS 运行策略、送电限制、储能运行方式、系统额定电压计划值；已有版本/参数冲突须处理。

现场 SN、安装位置、固件、现场值、厂家依据作为本环节待补事项折叠展示，同型号重复项保持合并。不要求为了推进建模填写猜测值，也不自动变为已确认。现场作业继续受安装 SOP 的资料要求约束。技术协同、来源记录及原始检查函数保留，但不作为独立 L6 作业步骤。

当前 CI-20 R5 在进入引导式安装时提示 4 个旧 iEMS 型号通信设置版本项，未自动修改其数值或来源。
