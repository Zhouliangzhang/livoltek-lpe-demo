# 步骤06 配置读回实施计划

按用户要求实施：逐台核对iEMS、零馈表、光伏、储能的配置，自动取冻结M1的批准配置。现有L5扩展只有planned/actual，不能把计划值或手录actual冒充批准值/自动读回。批准值从规范parameters的approved字段读取，要求review_status及值status均APPROVED、有source_ref且单位吻合；歧义、旧模板与缺依据均保留待确认。无批准值可进行候选值模拟对照，但不得计为批准一致。

- [x] 后端：生成端口级参数清单，按设备保留基线/实际值/差异/证据；03–05前置有效性、模型变化失效、幂等、模拟/真实隔离。只读不回写设备或M1。
- [x] 页面：四类设备分组，逐台展开，参数差异置顶，可定位M1和准备厂家协同草稿；保存历史。
- [x] 测试：批准值优先、计划不提升批准、单位/类型、缺读数、前置及刷新隔离；构建与实际CI-20页面截图。

差异处理：EPC核对现场参数与对象；厂家确认点表、单位、型号/固件及配置生效规则；需变更基线时回M1走批准。此步骤不自动覆盖差异，不将读回一致等同于系统正常运行或控制放行。

验证完成：后端全量82项通过，配置读回页面端到端测试通过；追加空值及零值/基线变化回归，配置专项3项通过；前端构建通过。实际CI-20 R6：22台、212项配置，尚无批准值；差异演示PV_03站号计划3、模拟读回4。98项候选相同、113项缺基线、1项差异，均未现场放行。
