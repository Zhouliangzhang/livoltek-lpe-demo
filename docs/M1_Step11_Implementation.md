# M1 步骤11：下发与读回

## 本次实现

从步骤10读取当前环境的冻结基线，校验内容哈希和归档哈希，按冻结设备、通信、计量及运行策略生成候选参数清单。站级策略归属 iEMS，不按设备数量复制到每台光伏或储能。

正式下发必须具备批准依据、可信写权限和现场身份核验。目前项目没有真实 iEMS 适配器及批准服务，因此实际下发始终阻断。离线不执行；模拟使用独立的后端模拟器；现场环境不显示模拟任务。

模拟覆盖候选值相同、差异、读回失败、不支持读回、拒令、确认丢失和执行中断。确认丢失及中断后停止后续设备动作。批准值与现场实际值保持未知；模拟读回另列，不能据此判定现场生效、策略激活或回退成功。缺参数的设备保持待补。

任务保存在 SQLite，绑定环境、冻结版本和请求ID。重复请求返回原任务；同一请求ID不得更换负载。浏览器保留未确认请求，可恢复原任务；历史任务不触发重发。基线失效、被篡改或环境不一致时拒绝演练。

页面按型号、主数据版本及固件分组，异常单独展示，提供逐参数差异、处理建议、原步骤入口、前后证据和事件日志。
