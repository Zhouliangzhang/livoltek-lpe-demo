# M2 系统逐项点检

按用户已确认方案：电气 → 通信 → 控制，以设备/回路点检记录为主，通信图折叠为辅助参考。检查结果与厂家依据分开；缺少受控厂家依据不得通过。记录绑定生成时模型，旧计划保留，新计划不继承结论。不涉及施工排期或设备就位。

实施与验证：
1. 新增按保存模型生成的版本化 checklist，电气回路、接地、通信接线/数据、控制映射/策略均关联具体对象。
2. 新增追加式点检结果、照片接口，验证对象归属、缺依据通过门禁、过期模型及历史隔离。
3. M2 展示三步清单、筛选、逐项展开、定位 L4/L5、下一项和下一步；旧资料留在折叠区。
4. 后端测试覆盖门禁、归属、持久化；浏览器验证顺序、记录、刷新与定位，截图实际页面。

当前指导版本 CHECKLIST-1 为草案，无厂家已批准的具体测试判据。用户可以记录异常、待确认、不适用（需原因），不能将草案记录为通过。页面不执行上电或控制动作。

验证结果：前端构建通过；37 项后台测试、7 项针对性浏览器测试通过，覆盖点检记录/照片、刷新恢复、缺依据通过门禁、过期模型、设备回路定位及旧工作包兼容。CI-20 当前清单为电气 96 项、通信 48 项、控制 41 项。新生成清单保存指导快照；旧计划按 CHECKLIST-1 兼容展示。厂家依据确认工作流尚未接入此新清单，当前项目全部保持草案，不能通过现有模板的模拟批准解锁。
